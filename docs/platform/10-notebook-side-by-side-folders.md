# Notebook Side-by-side and folders — first batch

The Notebook's **Side by side** switch opens a second page beside the active page. Two independently scrollable paper surfaces are shown on desktop; narrow screens stack them vertically. The current primary page retains all editing controls and tools. The secondary companion is intentionally **read-only** with text, strokes and objects visible, avoiding conflicts in the shared drawing selection and undo history. Use **Edit page** in the companion to swap the primary and secondary pages without losing either. A drop-down changes the companion page; page right-click includes **Open side by side**.

Folder improvements: expandable/collapsible nested folder tree (collapse state per device), aggregate page counts, Unfiled view, current folder indication and drag a page onto a folder/Unfiled. Rename, make child folder and safe folder removal remain available; removing folders never deletes their pages. Phone sidebar remains compact; full nested folder panel remains desktop-first.

Acceptance after Cloudflare compilation: select two different pages and compare text/drawings/objects; switch primary and edit it; close split; delete a second page and verify normal fallback; collapse folders/reload; drag pages into a nested folder and back to Unfiled; check role, light/dark and narrow-screen layout.

Build/browser acceptance is not asserted in this document.
